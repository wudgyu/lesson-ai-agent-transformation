# 错误码手册

## TS-999

下游超时。通常由外部网关、支付渠道或 HTTP 客户端超时引起。先查下游依赖的延迟与证书，不要先怀疑本服务的连接池。

## TS-998

连接被对端重置。常见于负载均衡摘除节点、TLS 握手失败或 keep-alive 超时。检查网络与网关配置。

## TS-500

本服务内部错误。查看异常栈与最近的部署；如果是数据库错误，结合 `HikariPool` 日志判断是否为连接池耗尽。

## 使用建议

错误码是精确匹配的好例子：`TS-999` 与 `TS-998` 在语义上很近，但处置完全不同。检索时不要让向量相似度单独决定，必须保留关键词检索作为第二路召回。
